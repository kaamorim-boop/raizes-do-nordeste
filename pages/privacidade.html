Privacidade e proteção de dados

Informações claras sobre os dados utilizados nesta demonstração acadêmica.

1. Quais dados podem ser utilizados?

Para simular cadastro, pedidos e fidelidade, o projeto pode utilizar nome, e-mail, telefone, unidade escolhida, itens do pedido e preferências de comunicação.

2. Para que são utilizados?

Os dados são usados apenas para demonstrar funcionalidades como identificação do cliente, processamento simulado do pedido, acompanhamento e programa de fidelidade.

3. Pagamentos

Nenhum pagamento real é realizado. O projeto não deve receber ou armazenar dados bancários reais. A tela de pagamento representa uma integração fictícia com um serviço externo.

4. Consentimento

O consentimento para comunicações promocionais é separado das demais finalidades. O usuário pode optar por não receber campanhas.

5. Armazenamento e segurança

Nesta versão acadêmica, os dados são mantidos no navegador por meio de localStorage. Em uma aplicação real, seriam necessários servidor, autenticação segura, controle de acesso, criptografia e políticas de retenção.

6. Direitos do titular

Em uma implementação real, o titular deve poder solicitar informações, correção, eliminação ou outras medidas previstas pela legislação aplicável, conforme as bases legais e limitações pertinentes.

🔒 Projeto acadêmico: não informe senhas reais, números de cartão ou outros dados sensíveis nesta demonstração.
